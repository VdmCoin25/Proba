# Рассыльщик по чатам (личный аналог Telegrand)

Ваши Telegram-аккаунты по очереди публикуют пост в список чатов. Всё управление,
включая добавление аккаунтов, — через своего бота, прямо с телефона.

## Хостинг (Render)
`render.yaml` описывает фоновый воркер (Starter) с диском 1 ГБ в `/var/data` —
там хранятся сессии, настройки и медиа поста. Переменные окружения:
`API_ID`, `API_HASH` (my.telegram.org), `BOT_TOKEN` (@BotFather), `ADMIN_ID` (@userinfobot).

Локально: `pip install -r requirements.txt`, заполнить `.env` по образцу `.env.example`, `python bot.py`.

## Панель (мини-апп)
Кнопка «Панель» в чате с ботом. Вкладки: Главная (запуск, прогресс, статистика, журнал),
Аккаунты (вход по номеру, вкл/выкл, вступление в чаты), Чаты, Посты (несколько, по очереди или
случайно; пост с медиа присылается боту), Настройки (интервалы, отчёты).
Доступ к API проверяется по подписи Telegram initData — открыть панель может только ADMIN_ID.

## Чтобы аккаунты не банили
- Пишите только в чаты, где реклама разрешена, соблюдайте их правила и slow mode.
- Интервал между кругами — не меньше slow mode в чатах (обычно 30–60+ минут).
- Новые аккаунты «прогрейте» несколько дней, прежде чем рассылать.
- При спам-блоке проверьте аккаунт в @SpamBot.
